1. WAKE WORD, PHONETIC VARIATIONS & ACTIVATION
================================================================================
Primary Wake Words:
  - "Hey Jarvis"
  - "Hello Jarvis"
  - "Hi Jarvis"
  - "Ok Jarvis" / "Okay Jarvis"
  - "Jarvis"
  - "Hey AC" / "Hello AC"
  - "Alexa"
  - "ஹே ஜார்விஸ்" / "ஜார்விஸ்"

Recognized Phonetic Variations & Mispronunciations:
  Jarvis is engineered with phonetic acoustic matching to catch variations:
  - "Hey Jervis" / "Jarvus" / "Javis" / "Jarves" / "Charvis"
  - "Travis" / "Service" / "Harvest" / "Starfish" / "Artist" / "Jar"

Interaction Tips:
  * INLINE COMMANDS: Speak wake word + command in one breath:
    e.g. "Hey Jarvis open notepad" or "Hey Jarvis what is the weather?"
  * CONTINUOUS CONVERSATION: After completing an action, Jarvis remains actively
    listening for 7.5 seconds for follow-up commands without repeating the wake word.
  * DOT (.) INSTANT EXECUTION: Say "dot" at the end of an utterance to trigger
    immediate execution (e.g. "open notepad dot open calculator dot").

================================================================================
Autonomous Care Mode activates when you express fatigue, illness, or distress:
  - "Jarvis turn down the volume, I'm feeling sick"
  - "I'm not feeling well, quiet everything"
  - "I have a bad headache, dim the lights"
  - "I have a fever and feel exhausted"
  - "Activate care mode" / "Wellness mode" / "Sick mode"

Autonomous Actions Taken:
  1. Reduces system volume to soothing level (15%).
  2. Dims screen brightness to 20-25% to minimize eye strain.
  3. Turns off simulated overhead room lighting.
  4. Automatically logs a wellness timestamp note into data/diary.json.
  5. Empathetically asks if you want to notify your emergency contact,
     reschedule upcoming tasks, or set a rest timer.

17. DYNAMIC CUSTOM COMMANDS & PASSKEY SECURITY
================================================================================
Voice Command Creation:
  - "Add custom command: when I say who is the boss say Abinesh is the creator"
  - "Add custom command: when I say open portfolio open url https://abinesh.dev"
  - "Add custom command: when I say launch project open folder C:\...\AC_VoiceAssistant"
  - "Add custom command: when I say open secret notes open file data/notes.txt"

File Syntax in 'data/custom_commands.txt':
  [secure] <trigger 1> | <trigger 2> => <action_type>: <target>

Supported Action Types:
  - url: <web address>      (e.g. "github trending => url: https://github.com/trending")
  - app: <app or exe>       (e.g. "launch code => app: code")
  - folder: <folder path>   (e.g. "open voice project => folder: C:\...\AC_VoiceAssistant")
  - file: <file path>       (e.g. "open notes => file: data/notes.txt")
  - say: <custom speech>    (e.g. "who is the boss => say: Abinesh is the creator!")
  - cmd: <terminal command> (e.g. "[secure] run tests => cmd: python test_jarvis.py")

Passkey Protection:
  - Default Passkey PIN: 1312
  - Spoken Authorization: Jarvis asks "Passkey required. Please state your authorization code."
  - Inline Voice Passkey: Say "run tests passkey 1312" in a single breath.
  - Built-in SafetyGuard blocks destructive operations (del /s, format, rm -rf, reg delete).
